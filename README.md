# Repo para practica de parciales de Desarrollo Web y Mobile 

[![Maximiliano López](https://img.shields.io/badge/GitHub-Maximiliano_López-B7E3FF?logo=github&logoColor=black)](https://github.com/maaxilopp)
[![Trinidad Bunge](https://img.shields.io/badge/GitHub-Trinidad_Bunge-FFD966?logo=github&logoColor=black)](https://github.com/trinibunge)

Repositorio de práctica para preparar los parciales de Desarrollo Web y Mobile. Reúne ejercicios, resoluciones y ejemplos hechos con HTML, CSS y JavaScript puro (sin frameworks ni librerías externas), pensados para repasar los temas clave de la materia.

## Objetivo

Tener un espacio ordenado donde practicar los distintos tipos de ejercicios que suelen aparecer en los parciales, revisar resoluciones y llegar a la instancia de evaluación con los conceptos frescos.

## Tecnologías
HTML5 — estructura y semántica
CSS3 — estilos, layout (Flexbox / Grid), responsive
JavaScript (ES6+) — lógica, manipulación del DOM, eventos

Sin frameworks ni dependencias: todo corre directamente en el navegador.

## Cómo usarlo

No requiere instalación. Para ver cualquier ejercicio:

Cloná el repositorio:
bash
   git clone https://github.com/maaxilopp/<nombre-del-repo>.git
Entrá a la carpeta del ejercicio que quieras revisar.
Abrí el archivo index.html en tu navegador (doble clic o arrastrándolo a la ventana).

Recomendado: usar la extensión Live Server de VS Code para recarga automática al editar.

## Contenidos
Maquetado y estructura con HTML semántico
Estilos y diseño responsive con CSS
Lógica e interactividad con JavaScript
Manipulación del DOM y manejo de eventos
Resolución de ejercicios tipo parcial
